# Guía de Postulación — Premio MapBiomas Venezuela 2026

Este documento sintetiza las bases oficiales, requisitos de entrega y lineamientos estratégicos para la postulación del proyecto **Agrotech Venezuela** a la **Segunda Edición del Premio MapBiomas Venezuela 2026**.

---

## 1. Contexto y Objetivo de la Convocatoria

Reconocer y premiar trabajos que, mediante el uso activo y reproducible de datos de **MapBiomas Venezuela** (Colección 3.0, 1985–2024), generen conocimiento científico inédito, propongan soluciones tecnológicas viables e incidan directamente en la formulación de políticas públicas, gestión ambiental o soberanía agroalimentaria comunitaria.

**Cita obligatoria de la fuente:** [Términos de Uso — MapBiomas Venezuela](https://venezuela.mapbiomas.org/terminos-de-uso/) *(Licencia Creative Commons Atribución 4.0 Internacional CC BY 4.0)*.

---

## 2. Categorías de Postulación

Agrotech Venezuela se postula de manera simultánea y convergente en dos categorías:

1. **Categoría General:** Trabajos de investigación, artículos científicos, desarrollos de software libre y aplicaciones espaciales que utilicen datos de MapBiomas.
2. **Políticas Públicas, Gestión Ambiental y Comunitaria:** Aplicación práctica de datos territoriales para soluciones concretas en la producción sustentable, reducción de incertidumbre en créditos de carbono (MRV) y resiliencia rural.

## 4. Requisitos Formales de Formato y Presentación

- **Tipología Documental Aceptada:** Artículo científico/técnico, reporte exhaustivo, repositorio de código abierto y visor espacial interactivo.
- **Extensión Máxima Permitida:** Hasta **10.000 palabras** (cuerpo principal: introducción, metodología, resultados, discusión y conclusiones). Excluye resúmenes, anexos cartográficos, código fuente y referencias.
- **Idiomas:** Español e Inglés (incluye *Abstract* y *Keywords* bilingües).
- **Entregables Requeridos:** Documento PDF consolidado, repositorio GitHub público con licencia libre (MIT) y acceso a plataforma WebGIS demostrativa en vivo.

## 6. Checklist de Verificación y Auditoría del Expediente

- [x] **Manuscrito Científico**: Borrador validado en 3.178 palabras (< 10.000 palabras permitidas).
- [x] **Cita de Atribución Obligatoria**: Cita formal a los Términos de Uso de MapBiomas Venezuela (CC BY 4.0) incluida en portada, pie de página y bibliografía.
- [x] **Reproducibilidad y Código Abierto**: Repositorio GitHub público bajo Licencia MIT con 233 tests automatizados y compilación Next.js limpia.
- [x] **Anexos Analíticos y Visuales**: Figuras vectoriales de alta resolución generadas con Plotly, leyendas interpretativas y tablas estructuradas.
- [x] **Plataforma WebGIS Operativa**: Despliegue en producción con arquitectura Dual-Mode UI (Modo Productor Fácil campesino y Modo Técnico).
