# Proposal

## Why

During a comprehensive repository and documentation audit, visual inspection revealed that several showcase screenshots in `docs/images/showcase/` (specifically `06_perfil_postulacion_mapbiomas.png` and `01_webgis_3_niveles.png`) are outdated: they display old test counts (`TRL 4 (252 tests)` instead of the current 278 tests passing), outdated badge phrasing (`Autoevaluación Anexo II` instead of `Criterios Oficiales Anexo II`), a missing sidebar item (`Manual & Guías`), and development overlay warning badges (`N 1 Issue ✕`). Furthermore, the repository contains ~1.55 MB of redundant or unreferenced binary assets (duplicate `.jpg` infographics byte-for-byte identical to the active `.png`, and tracked intermediate slide frames in `slides_png/` generated by a video script). Cleaning these files, confining intermediate frames to `.gitignore`, and refreshing the showcase screenshots ensures high fidelity, maximum repository hygiene, and a clean, lightweight repository for evaluators and researchers.

## What Changes

- **Purge Redundant Binary Duplicates**: Delete unreferenced duplicate files `docs/flujo_inteligencia_agricola.jpg` and `public/images/flujo_inteligencia_agricola.jpg` (saving ~513 KB), keeping solely the authoritative `public/images/flujo_inteligencia_agricola.png` referenced throughout the app and documentation.
- **Untrack Intermediate Video Frames & Confine to Local**: Remove the `slides_png/` folder (8 PNG files totaling ~1.03 MB) from Git tracking while preserving its generation logic in `backend/scripts/generate_slides_video.py` for local on-demand video creation.
- **Expand `.gitignore` Rules**: Add `slides_png/`, `*.webm`, `*.mov`, `*.tmp`, and `*.bak` to `.gitignore` so local scratch assets and intermediate multimedia renders remain strictly local.
- **Refresh Showcase Documentation Screenshots**:
  - Update `docs/images/showcase/06_perfil_postulacion_mapbiomas.png` to reflect the current platform state: `TRL 4 Validado (278 Tests)` and `Criterios Oficiales Anexo II` without Next.js dev overlay badges.
  - Update `docs/images/showcase/01_webgis_3_niveles.png` to include the `Manual & Guías` sidebar navigation item.
  - Update `docs/images/showcase/03_retorno_inversion_costeo.png` to eliminate development error indicators (`N 1 Issue ✕`).
- **Frontend Image Loading Optimization**: Ensure static documentation and showcase images include `loading="lazy"` and `decoding="async"` attributes where appropriate.
- **Zero Regression Verification**: Validate that all 278 automated tests (224 Jest + 54 Pytest) pass, 0 TypeScript errors exist, and all 32 Next.js routes build cleanly.

## Capabilities

### Modified Capabilities
- `repository-showcase-and-evaluator-guide`: Update visual showcase requirements to mandate that documentation screenshots faithfully reflect the current test substrate (278 tests), official criteria naming (`Criterios Oficiales Anexo II`), full navigation items, and clean captures devoid of development error overlays.
- `repository-hygiene-and-secret-prevention`: Update hygiene requirements to exclude intermediate generated multimedia assets (`slides_png/`, video formats) and purge dead unreferenced binary duplicates from Git tracking.

- **Affected Files & Directories**:
  - `docs/images/showcase/` (refreshed screenshot assets)

  - `.gitignore` (updated with exclusion patterns)
