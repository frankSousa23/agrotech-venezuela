# Design

## Context

See `proposal.md` for background and motivation. The project is an operational agro-climatic intelligence platform for Venezuela with a verified testing substrate of 278 automated tests (224 Jest + 54 Pytest). A thorough documentation and asset audit revealed:
1. Two binary clones (`docs/flujo_inteligencia_agricola.jpg` and `public/images/flujo_inteligencia_agricola.jpg`) that share the exact SHA-256 hash as `public/images/flujo_inteligencia_agricola.png` while having zero references in codebase or Markdown files.
2. An intermediate slide frame directory (`slides_png/`, ~1.03 MB) generated by `backend/scripts/generate_slides_video.py` that is tracked in Git despite having zero references in docs or web views.
3. Showcase screenshots in `docs/images/showcase/` captured during earlier milestones showing outdated metrics (252 tests instead of 278, "Autoevaluación Anexo II" instead of "Criterios Oficiales Anexo II", missing `Manual & Guías` sidebar entry, and Next.js dev overlay badges).

## Goals / Non-Goals

**Goals:**
- Eliminate 100% of redundant binary duplicate files without breaking any documentation or frontend view.
- Untrack `slides_png/` from Git while keeping the video generator script fully functional for local generation.
- Expand `.gitignore` to keep local scratch assets, intermediate frames, and video formats strictly local.
- Refresh showcase screenshots (`06_perfil_postulacion_mapbiomas.png`, `01_webgis_3_niveles.png`, `03_retorno_inversion_costeo.png`) so they faithfully depict the current platform without dev overlays.
- Add `loading="lazy"` and `decoding="async"` attributes to static documentation images in Next.js views for enhanced rural network performance.
- Maintain 100% pass rate across the 278 automated test suite and zero TypeScript compilation errors.

**Non-Goals:**
- Modify agricultural calculation engines (Shoelace WGS84, Saxton-Rawls, Kamprath, GDD, SAR dB).
- Remove third-party packages or alter dependencies in `package.json`.
- Modify the 7 official PDF dossiers submitted for the MapBiomas Prize.

## Decisions

### 1. Canonical Infographic Asset Strategy
- **Decision**: Keep `public/images/flujo_inteligencia_agricola.png` as the single canonical source of truth for the 5-stage precision agriculture workflow infographic, and permanently delete the two identical `.jpg` clones (`docs/flujo_inteligencia_agricola.jpg` and `public/images/flujo_inteligencia_agricola.jpg`).
- **Rationale**: Both `.jpg` files have zero references across the entire repository and are byte-for-byte identical to the `.png`. Removing them frees ~513 KB immediately with zero risk.
- **Alternatives Considered**: Keeping them for backwards compatibility (rejected: ripgrep confirmed zero inbound links; keeping them encourages confusing link targets).

### 2. Intermediate Slide Frames Isolation
- **Decision**: Remove `slides_png/` from Git tracking (`git rm -r --cached slides_png`) and add `slides_png/` to `.gitignore`. Leave the directory on disk for local use if desired, or remove from local tracking.
- **Rationale**: These 8 slide PNGs (~1.03 MB) are temporary frames generated by `backend/scripts/generate_slides_video.py` before compiling the final MP4 video. The final video (`*.mp4`) is already ignored by `.gitignore`; the intermediate frames must follow the same policy.
- **Alternatives Considered**: Keeping them in Git so users don't need to run Python to view slides (rejected: slides are for video compilation, not documentation, and bloat repo size).

### 3. Comprehensive `.gitignore` Expansion
- **Decision**: Add wildcard patterns for intermediate multimedia formats (`slides_png/`, `*.webm`, `*.mov`, `*.tmp`, `*.bak`) to `.gitignore`.
- **Rationale**: Prevents accidental commits of temporary test recordings, browser subagent artifacts, and local scratch files.

### 4. Showcase Screenshot Refresh Workflow
- **Decision**: Re-capture or update the showcase screenshots in `docs/images/showcase/`:
  - `06_perfil_postulacion_mapbiomas.png`: Update to show `278 tests`, `Criterios Oficiales Anexo II`, and hide Next.js development overlays.
  - `01_webgis_3_niveles.png`: Capture the complete sidebar navigation hierarchy including `Manual & Guías`.
  - `03_retorno_inversion_costeo.png`: Eliminate the development error overlay badge (`N 1 Issue ✕`).
- **Rationale**: High-fidelity visual documentation creates immediate confidence for jurors and evaluators inspecting the repository on GitHub without running the application locally.

### 5. Frontend Image Performance Attributes
- **Decision**: Ensure that static image elements in Next.js views (such as the infographic in `src/app/dashboard/postulacion/page.tsx`) explicitly declare `loading="lazy"` and `decoding="async"`.
- **Rationale**: Optimizes initial paint time and reduces memory footprint, especially on mobile devices or rural low-bandwidth networks.

## Risks / Trade-offs

- **[Risk]** Broken image link after deleting redundant `.jpg` files.
  - *Mitigation*: Confirmed via exhaustive regex ripgrep that zero files reference `.jpg`. All references explicitly use `public/images/flujo_inteligencia_agricola.png` or relative paths to it.
- **[Risk]** `slides_png/` untracking breaks video generator script.
  - *Mitigation*: Inspected `backend/scripts/generate_slides_video.py`; it creates `slides_png/` dynamically with `os.makedirs(slides_dir, exist_ok=True)`. Untracking from Git does not impact local script execution.
- **[Risk]** Automated test regressions from frontend image attribute additions.
  - *Mitigation*: Run the full test suite (`npm run test:all`) and Next.js build validation (`npm run build`) to ensure 278/278 tests pass and 32 routes compile cleanly.
