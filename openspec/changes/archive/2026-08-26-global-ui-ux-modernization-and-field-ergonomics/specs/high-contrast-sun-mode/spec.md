## Purpose

Enables a high-contrast sunlight theme tailored for rural outdoor environments and direct tractor/field usage.

## ADDED Requirements

### Requirement: Sunlight High-Contrast Theme Toggle
The system SHALL provide a header switch that toggles the `data-theme="sunlight"` attribute on the root document.

#### Scenario: Activating Sunlight Mode
- **WHEN** user clicks the "Modo Pleno Sol" toggle in the dashboard header
- **THEN** high-contrast text styles, pure white backgrounds, and solid dark borders are applied for daytime glare resistance.
