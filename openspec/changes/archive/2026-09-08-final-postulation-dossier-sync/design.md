## Context

See `proposal.md` for motivation. While the live platform, automated test suite (233 passing tests: 179 Jest + 54 Pytest), TypeScript compilation (0 errors), and Next.js 16 production build (30 routes) are fully calibrated to TRL 6, five static documentation files and capability specs retain obsolete references to 227 tests and TRL 7. 

## Goals / Non-Goals

**Goals:**
- Eliminate all remaining cognitive discrepancies by aligning text, headers, and markdown links across `docs/MEMORANDO_POSTULACION.md`, `DEVELOPING.md`, `README.md`, and `GUIA_POSTULACION.md` to TRL 6 and 233 automated tests.
- Update main capability specifications under `openspec/specs/` to reflect TRL 6 and 233 tests.
- Recompile publication-grade PDFs (`scripts/compile_all_docs_to_pdf.js`) so that official deliverables in `public/docs/` contain synchronized metrics.
- Ensure the full regression test suite (`npm run test:all`) and production build (`npm run build`) remain 100% green.

**Non-Goals:**
- Altering core GIS algorithms, Leaflet hooks, FastAPI Python routines, or Next.js App Router endpoints (which are already verified and certified).
- Modifying UI components (already updated to TRL 6 and 233 tests in the previous change).

## Decisions

1. **Single Source of Truth for Institutional Memorandum**:
   - *Decision*: Replace the outdated contents of `docs/MEMORANDO_POSTULACION.md` with the finalized, polished content from `public/docs/MEMORANDO_POSTULACION.md` (which includes TRL 6, 233 tests, FinOps, and software-first BYOD).
   - *Alternative Considered*: Manually patch isolated lines in `docs/MEMORANDO_POSTULACION.md`. Rejected because `public/docs/` also features improved table layouts and removed raw ASCII diagrams.

2. **Consistent Anchor Naming in Developer Guidelines**:
   - *Decision*: Update `DEVELOPING.md` section 4 header from `## 🧪 4. Suite Completa de Pruebas y Verificación (227 Tests)` to `(233 Tests)`, and simultaneously update the link anchor in `README.md` to `#4-suite-completa-de-pruebas-y-verificación-233-tests`.
   - *Alternative Considered*: Leave the anchor pointing to a generic slug without the test count. Rejected because the explicit test count in the anchor reinforces immediate verification for technical auditors.

3. **Compilation Pipeline Execution**:
   - *Decision*: Execute `node scripts/compile_all_docs_to_pdf.js` to regenerate `Guia_Postulacion_MapBiomas_2026.pdf` and `Memorando_Postulacion_Agrotech_2026.pdf` after markdown updates, verifying PDF generation without Puppeteer failures.

## Risks / Trade-offs

- [Risk] PDF generation script fails due to Puppeteer sandbox or npm cache dependency path → Mitigation: `scripts/compile_all_docs_to_pdf.js` contains fallback resolution for puppeteer and md-to-pdf; run with appropriate node process and verify target files exist in `public/docs/`.
- [Risk] Broken anchor link in README.md → Mitigation: Match exact lowercase Spanish slug generated by GitHub Flavored Markdown for the updated DEVELOPING.md header.
