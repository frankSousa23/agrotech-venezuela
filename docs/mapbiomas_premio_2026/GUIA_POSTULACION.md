# Guía de Postulación — Premio MapBiomas Venezuela 2026

Este documento sintetiza las bases oficiales, requisitos de entrega y lineamientos estratégicos para la postulación del proyecto **Agrotech Venezuela** a la **Segunda Edición del Premio MapBiomas Venezuela 2026**.

---

## 1. Contexto y Objetivo de la Convocatoria

Reconocer y premiar trabajos que, mediante el uso activo y reproducible de datos de **MapBiomas Venezuela** (Colección 3.0, 1985–2024), generen conocimiento técnico y científico, propongan soluciones tecnológicas viables e incidan directamente en la formulación de políticas públicas, gestión ambiental o soberanía agroalimentaria comunitaria.

**Cita obligatoria de la fuente:** [Términos de Uso — MapBiomas Venezuela](https://venezuela.mapbiomas.org/terminos-de-uso/) *(Licencia Creative Commons Atribución 4.0 Internacional CC BY 4.0)*.

---

## 2. Categoría Oficial de Postulación

Agrotech Venezuela se postula de forma unívoca y focalizada en la:

- **Categoría General:** Trabajos desarrollados por profesionales, técnicos, docentes o investigadores que utilicen datos o productos de MapBiomas Venezuela con fines de investigación, educativos o desarrollo de software libre y plataformas geoespaciales.
- **Formato Oficial**: **Artículo Técnico** (según lo estipulado en las bases 3.1 y 3.11.1).

## 4. Requisitos Formales de Formato y Presentación

- **Tipología Documental Aceptada:** Artículo Técnico, reporte técnico de software, repositorio de código abierto y visor espacial interactivo.
- **Extensión Máxima Permitida:** Hasta **10.000 palabras** (cuerpo principal: introducción, metodología, resultados, discusión y conclusiones). Excluye resúmenes, anexos cartográficos, código fuente y referencias.
- **Idiomas:** Español e Inglés (incluye *Abstract* y *Keywords* bilingües).
- **Entregables Requeridos:** Documento PDF consolidado (Artículo Técnico), repositorio GitHub público con licencia libre (MIT) y acceso a plataforma WebGIS demostrativa en vivo.

## 6. Checklist de Verificación y Auditoría del Expediente

- [x] **Manuscrito Técnico**: Artículo Técnico validado en ~3.200 palabras (< 10.000 palabras permitidas).
- [x] **Cita de Atribución Obligatoria**: Cita formal a los Términos de Uso de MapBiomas Venezuela (CC BY 4.0) incluida en portada, pie de página y bibliografía.
- [x] **Reproducibilidad y Código Abierto**: Repositorio GitHub público bajo Licencia MIT con 233 tests automatizados y compilación Next.js limpia.
- [x] **Nivel de Madurez Tecnológica**: TRL 4 (Prototipo Funcional de Software Validado en Entorno de Desarrollo Local con datos satelitales reales).
- [x] **Plataforma WebGIS Operativa**: Despliegue en producción con arquitectura Dual-Mode UI (Modo Productor Fácil campesino y Modo Técnico).
